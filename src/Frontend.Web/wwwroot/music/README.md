# Baggrundsmusik (SCRUM-167)

`menu.mp3` er "Vintage Menu" af iamoneabe fra OpenGameArt
(https://opengameart.org/content/vintage-menu), licens CC0 (public domain, ingen kreditering krævet).

Kodet om til mono, 64 kbit/s og normaliseret til -23 LUFS, så filen er lille (ca. 2,5 MB) og ligger
roligt i baggrunden. Afspilles af `wwwroot/js/bgMusic.js` på forsiden og i lobbyen, meget lavt
(en brøkdel af Musik-indstillingen).
